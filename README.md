# GameSystems

Reusable Unity systems for abilities, characters, sequencing, stats, feedbacks, playables, hooks,
and procedural level generation.

## Documentation

The generated API reference and architecture guide are published at:

https://mathonatpierre.github.io/GameSystems/

Runtime and Editor source code lives under `Assets/GameSystems` and can be copied directly into a
Unity project while the package structure is being finalized.
